# Enterprise AI Operations Copilot

An operations copilot that answers questions like "Why is the payments service showing a latency spike?" using runbooks (RAG), monitoring data, and human-approved remediation.

- [Development guide](docs/development.md)
- [Deployment (images, Kubernetes)](docs/deployment.md)
- [Implementation plan](docs/plan.md)

Quick start: `make up`, `make createsuperuser you@example.com`, then open the UI at http://localhost:5173 (API docs at http://localhost:8000/docs).
